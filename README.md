A modern, responsive, and high-performance personal portfolio and biodata webpage showcasing my background, core technical skills, professional work experience, education, and industry credentials as a **Quality Assurance Engineer**.

---

## 🌟 Key Features

- **Professional Header & Identity**: Crisp headshot with availability indicator, title tagline, and direct contact/social links.
- **Core QA Skills & Tooling Grid**: Highlights proficiencies across testing methodologies (Manual, Automation, API Testing, Regression) and modern QA tools (Cypress, Postman, Jira, Git, DevTools).
- **Interactive Work Experience Timeline**: Structured career timeline detailing roles, responsibilities, and achievements at **Data Science Nigeria**, **Timart**, **Sysbit Tech**, and **DANA Pharmaceutical**.
- **Credentials & Education Showcase**: Card-based overview of academic degrees and verified certifications with direct credential verification links.
- **Interactive Contact Form**: Integrated with Formspree for direct messaging, client-side input validation, loading states, and dynamic toast notifications.
- **Direct CV Download**: Quick-action button enabling visitors and recruiters to download my latest resume in PDF format.
- **Mobile-First Responsive Design**: Optimized typography and layouts built with modern CSS custom properties (design tokens), ensuring seamless viewing across phones, tablets, and 4K displays.

---

## 🛠️ Built With

- **HTML5**: Semantic, accessible markup structure.
- **Vanilla CSS3**: Custom design tokens, Flexbox, CSS Grid, smooth micro-interactions, and responsive media queries.
- **JavaScript (ES6+)**: Dynamic copyright date, asynchronous form submission via Fetch API, regex email validation, and toast notification system.
- **Google Fonts**: [Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans) & [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono).
- **Formspree**: Serverless contact form handling.

## 🚀 Running Locally

To run this project on your local machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Auna19/Biodata.git
   cd Biodata
   ```

2. **Open with Live Server:**
   - In **VS Code / Antigravity IDE**, right-click `index.html` and select **"Open with Live Server"**.
   - Or use Node.js from your terminal:
     ```bash
     npx serve .
     ```
   - Open your browser at `http://localhost:3000` (or `http://localhost:5500`).
